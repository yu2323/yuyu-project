# 灵枢玉简 Lingyu Jade v0.2.1

给 SillyTavern 使用的“世界内设备”前端扩展原型。修真世界里是玉简，后续可复用成现代手机、星际终端等皮肤。

## 当前功能

- 顶部酒馆工具栏“卷轴”入口，带未读角标
- SillyTavern 原生 Popup 主面板，针对移动端优先
- 首页：地点 / 时辰 / 灵石 / 世界异动
- 灵讯：联系人、未读数、聊天记录、手动发送
- 留影：类似朋友圈的信息流，可点赞、自己发动态
- 坊市：价格 / 库存 / 涨跌状态
- 人物簿：关系、位置、最近活动
- 手动刷新世界：追加测试动态 + 测试灵讯
- 状态写入当前聊天 `chatMetadata`，不同聊天存档互不串线

## v0.2.1｜移动端可读性改版

v0.2.0 已解决移动端打开稳定性，但实机截图暴露出新的纯视觉问题：羊皮纸纹理过重、文字对比度不足、顶部信息拥挤、首页层级弱、底部导航过淡。

v0.2.1 只改 UI，不碰 AI、Prompt 和数据逻辑：

- 继续使用 SillyTavern 原生 Popup 生命周期
- 对当前玉简 Popup 去掉额外纹理背景，改为干净暖浅底
- 隐藏原生 Popup 自带关闭钮，只保留插件内明确 `×`
- 主文字改为高对比深色，副信息改为中灰
- 顶部移除印章和版本号，保留标题 / 副标题 / 刷新 / 关闭
- 首页重排为“当前所在 + 身份 / 时辰 / 灵石”状态卡
- 附近异动、灵讯、朋友圈、坊市、人物簿统一提高字号和行距
- 底部导航改用 Font Awesome 图标，并强化激活态

## v0.2.0 为什么重做 UI

v0.1.x 使用自制 `position: fixed` 面板、悬浮按钮和移动端事件兼容层，在第三方搭建的手机 SillyTavern 上出现过“按钮点不开 / 闪一下就关闭 / 反复打开不稳定”等问题。

v0.2.0 停止继续给旧事件链打补丁，改为已验证的移动端基线：

- 主面板使用 SillyTavern 原生 `Popup(..., POPUP_TYPE.DISPLAY)`
- 顶部入口使用原生 `.drawer > .drawer-toggle > .drawer-icon` 结构
- 入口只保留一套 `click` 逻辑
- 删除旧 `bootstrap.js` 中转层，扩展直接加载 `index.js`

## 当前阶段

v0.2.1 仍然**暂不接 AI，也不修改正文 Prompt**。当前只验证移动端视觉与交互：

1. 顶部卷轴按钮能打开 / 再次关闭玉简
2. 面板不会闪退
3. 插件内 `×` 可以正常关闭
4. 首页文字对比、字号、留白是否舒服
5. 灵讯、留影、坊市、人物簿仍能切换和操作

通过后再接后台生成、剧情事实读取和重要事件同步。
