# 灵枢玉简 Lingyu Jade v0.1.0

给 SillyTavern 使用的“世界内设备”前端扩展原型。

## 当前功能

- 右下角悬浮“简”按钮
- 移动端优先的玉简面板
- 首页：地点 / 时辰 / 灵石 / 世界异动
- 灵讯：联系人、未读数、聊天记录、手动发送
- 留影：类似朋友圈的信息流，可点赞、自己发动态
- 坊市：价格 / 库存 / 涨跌状态
- 人物簿：关系、位置、最近活动
- 手动刷新世界：追加一条动态 + 一条灵讯
- 所有状态写入当前聊天 `chatMetadata`，不同聊天存档互不串线

## v0.1 暂不接模型

这一版先测试 UI、交互和存档隔离，不调用 AI，也不修改正文 prompt。

后续计划：

1. 接 `generateQuietPrompt()`，后台生成 NPC 灵讯、朋友圈和世界新闻。
2. 读取最近正文的必要事实，让玉简和剧情处于同一世界。
3. 只把重要玉简事件同步回正文上下文，避免 token 被朋友圈淹没。
4. 加朋友圈可见范围、评论树、删动态、屏蔽、消息延迟和 NPC 离线时间线。
5. 通用皮肤：修真玉简 / 星际终端 / 现代手机。

## 安装

在 SillyTavern 的第三方扩展安装入口粘贴本仓库 Git URL：

`https://github.com/yu2323/yuyu-project`

> 当前仓库为 private 时，SillyTavern 是否能直接拉取取决于本机 Git 的 GitHub 认证状态；如果安装器拉不到，可以先改为 public，或在本机配置 GitHub 凭据后再安装。
